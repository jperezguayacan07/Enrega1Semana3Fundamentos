# Proyecto - Conceptos Fundamentales de Programación

## Politécnico Grancolombiano

Proyecto desarrollado para la asignatura **Conceptos Fundamentales de Programación**.

## Descripción

El proyecto permite generar archivos de información relacionados con productos, vendedores y ventas. Posteriormente, procesa esta información para generar reportes en formato CSV.

El proyecto se desarrolla en **Java** y utiliza archivos de texto como fuente de información.
